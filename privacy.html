隱私政策

更新及生效日期：2026 年 10 月 21 日

本政策由觀象個人開發者提供，適用於觀象的離線、無線上 AI 版本，以及本產品介紹與支援網站。我們重視你的個人資料，以下說明資料如何儲存、何時可能離開裝置，以及你可以如何管理。

重點摘要

觀象無需帳號、不含廣告及第三方追蹤分析 SDK，不會自動將你的演算、所問或札記傳送至開發者的伺服器，也不會傳送給線上 AI 服務。系統備份、你主動分享或聯絡支援，以及造訪本網站，另依下列說明處理。

本機資料匯出與刪除分享與支援網站託管聯絡我們

一、App 內的資料與用途

觀象的經文、注解與演算解讀隨 App 提供，核心功能不依賴網路。App 不要求註冊或登入，也不提供線上 AI 生成服務。

以下資料由 App 儲存在你的裝置上，用於提供對應功能：

  • 演算結果、動爻、演算方式與過程、時間及時區，用於保留及回看演算記錄。
  • 你自行填寫的所問、卦例札記及閱讀札記，用於記錄個人思考。
  • 收藏、閱讀進度及未完成的演算，用於接續使用。
  • 語言等使用偏好，用於維持你的顯示設定。

上述內容不會由 App 自動上傳給開發者。我們未在此版本加入廣告、跨 App 追蹤、第三方行為分析 SDK，亦不出售你的個人資料。

二、裝置儲存與系統備份

觀象不提供由開發者營運的帳號系統或雲端同步服務。資料一般保留於裝置中，直到你刪除相關內容或刪除 App。

若你啟用了 iCloud 備份、電腦備份或裝置移轉，系統可能將 App 資料包含於備份或移轉內容中，具體取決於 Apple 的功能及你的設定。這類處理由 Apple 或你選用的備份工具提供，開發者無法存取你的系統備份。

三、查閱、匯出與刪除

你可以直接在 App 中查閱與編輯自己的記錄及札記。在「設定 → 隱私與資料」中，可使用「匯出全部記錄」及「刪除全部本機資料」。其中的匯出功能包含已儲存的演算記錄與閱讀札記。

刪除 App 通常會移除其裝置內資料；iOS 的「卸載 App」可能保留文件與資料，與「刪除 App」不同。已匯出的檔案、已傳送的郵件及系統備份不會隨 App 內刪除而一併移除，請到相應位置另行管理。

由於我們未持有你的本機記錄，無法代你讀取、還原或遠端刪除這些內容。請在刪除或更換裝置前，先自行匯出需要保留的資料。

四、主動分享與聯絡支援

只有在你主動使用系統分享、匯出、郵件或外部連結時，你選擇的內容才會交由相應 App 或服務處理，並適用其隱私政策。請在確認分享或傳送前檢查內容，避免不必要地公開私人所問或札記。

若你透過電子郵件聯絡我們，我們會收到你的郵件地址、郵件內容及你主動提供的附件或裝置資訊。這些資料僅用於回覆、處理問題及必要的後續聯絡，不用於廣告行銷。我們會在處理問題所需期間保留相關郵件；目的完成後於不再需要時刪除，但法律要求保留的情況除外。

如需查詢、更正或刪除你曾透過支援郵件提供的個人資料，請使用下方聯絡方式提出；我們會在確認必要資訊後處理。

五、Apple 平台服務

App Store 下載、系統備份及系統診斷由 Apple 提供。Apple 可能依你的系統設定及其政策處理相關資料，並向開發者提供平台統計或診斷資訊。這與觀象自行加入第三方追蹤 SDK 不同。

相關選項請至裝置的「設定 → 隱私權與安全性 → 分析與改進」等系統頁面查看；實際名稱可能因系統版本不同而有所差異。詳情請參閱 Apple 隱私政策。

六、本網站與 GitHub Pages

本網站供產品介紹、使用支援及隱私政策查閱，發佈於 GitHub Pages 時，由 GitHub 提供靜態網頁託管。頁面不使用廣告、追蹤程式、分析指令碼、外部字型或第三方表單，也不主動設定 Cookie。

當你造訪網站時，GitHub 作為託管服務提供者，可能為提供服務及維護安全而處理 IP 位址等技術資料。這不代表 App 內的私人記錄會上傳到網站。GitHub 的處理方式請參閱 GitHub 隱私聲明。

七、政策更新

若資料處理方式或產品功能變更，我們會更新本政策及頁首日期。若未來新增需要收集或傳送個人資料的功能，會在啟用前清楚說明，並在適用法律要求下取得你的同意。本政策不表示目前提供線上 AI、雲端同步或其他尚未推出的功能。
